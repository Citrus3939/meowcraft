# Meow Craft

Meow Craft 是一个可爱二次元风格的 Cosplay 假毛订制工坊静态网页 Demo。

## 内容

- 随机简体猫图案 Logo
- 假毛订制服务介绍
- 定制流程与价格参考
- 作品展示占位
- 在线定制需求表单
- 前端模拟订单查询

## 本地预览

直接用浏览器打开 `index.html` 即可预览。

也可以在仓库目录运行一个静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 后续替换项

- 将联系方式中的“待补充”替换为微信、QQ、邮箱、店铺链接或二维码
- 将作品展示占位替换为真实作品图片
- 将前端模拟表单接入后台、邮箱、飞书 / Notion / Google 表格等真实收集方式
- 将订单查询接入真实数据库或后台管理系统
