# 交易日志表格

一个无需后端和依赖的静态交易记录页面，用于记录每一笔交易的关键信息：

- 交易理由
- 入场/出场时间与价格
- 自动计算持仓时间
- 交易截图上传与预览
- 交易时量能
- 事后复盘
- 止损、止盈
- 自动计算盈亏比
- 时间段交易次数和总盈亏统计
- 日历红/绿点标记每日盈亏
- 盈亏增长曲线

## 使用方式

直接用浏览器打开 `index.html` 即可使用。交易数据会保存在当前浏览器的本地存储中，刷新页面后仍会保留。

## 文件说明

- `index.html`：页面结构和交易表格
- `styles.css`：页面样式
- `app.js`：新增、编辑、删除、截图预览、本地保存、盈亏统计、日历标记与增长曲线逻辑
